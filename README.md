# Carecor website redesign – Draft 1

A clickable prototype of the redesigned carecor.com, prepared for leadership review.

- Live preview: GitHub Pages (Settings → Pages)
- Text marked in orange is a placeholder that still needs facts or approval.
- Forms, the AI job match and Ask Carecor are demos. Nothing is sent or stored.
- Job listings are a snapshot of the Carecor job board taken on October 27, 2026.
- Photos are placeholders. Staff photos and names need consent before launch.

Add `?presenter` to the address to show the presenter tools in the footer.
